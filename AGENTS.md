# AGENTS.md

## General Guidelines

- Keep code simple, readable, and maintainable.
- Avoid unnecessary complexity and overengineering.
- Follow established conventions and best practices.
- Prefer straightforward solutions over unnecessary abstractions.
- Keep changes focused and avoid unrelated modifications.

## Comments

- Keep comments simple, clear, and minimal.
- Avoid changelog-style comments describing changes or fixes.
- Comments should describe the current state or purpose of the code, not its history.
- Follow the commenting conventions of the language being used.
- Avoid comments that simply repeat what the code already makes clear.

## Code Quality

- Write clean, consistent, and easy-to-understand code.
- Use meaningful names for variables, functions, and classes.
- Avoid unnecessary duplication.
- Handle errors appropriately.
- Only introduce abstractions when they provide clear value.
- Follow the existing project structure and coding style.

## Best Practices

- Prefer maintainable and practical solutions.
- Avoid adding dependencies unless necessary.
- Keep functions focused and responsibilities clear.
- Do not introduce unnecessary configuration or infrastructure.
- Consider existing functionality before modifying code.

## Testing

- All tests must be temporary.
- Use tests to verify the implementation, then delete the test files.
- Do not leave test files or testing artifacts in the project.

## Before Finishing

- Review the implementation for unnecessary complexity.
- Ensure the code follows the project's conventions.
- Remove unused code and unnecessary comments.
- Run relevant tests or checks when available.
